# Neo Learn

Кроссплатформенный тренажёр программирования для iOS и Android. Учите **Rust**, **C++** и **JavaScript** короткими уроками и практикой, без лишней истории и теории, которая не нужна в работе.

Интерфейс сделан в стиле неоморфизма на основе токенов Material Design 3.

## Возможности

- Три курса: Rust, C++, JavaScript
- Короткие уроки и практические задания
- Несколько уровней сложности
- Поиск по урокам
- Конспекты в PDF
- Светлая и тёмная темы
- Выбор акцентного цвета (Material You, готовые пресеты, свой цвет)
- Адаптация под экраны телефонов

## Чему учит

| Курс | Темы |
|------|------|
| Rust | владение и заимствование, безопасная работа с памятью без сборщика мусора, основы системного программирования |
| C++ | указатели и управление памятью, производительный низкоуровневый код |
| JavaScript | современный синтаксис, асинхронность, основы фронтенда и веб-разработки |

## Стек

- Интерфейс: HTML, CSS, JavaScript (ES-модули)
- Оболочка для мобильных платформ: [Tauri 2](https://v2.tauri.app/) (Rust)
- Дизайн: неоморфизм + Material Design 3

## Структура проекта

```
neo-learn/
├── index.html      # разметка
├── styles.css      # стили, дизайн-токены, темы
├── main.js         # логика приложения (ES-модуль)
├── assets/         # иконки, шрифты, изображения
└── src-tauri/      # Rust-часть и конфигурация Tauri
```

## Быстрый старт

### Требования

- [Node.js](https://nodejs.org/) LTS
- [Rust](https://www.rust-lang.org/tools/install)
- [Зависимости Tauri 2](https://v2.tauri.app/start/prerequisites/) для вашей ОС
- Для Android: Android Studio, Android SDK и NDK
- Для iOS: macOS и Xcode

### Установка

```bash
git clone <URL-репозитория>
cd neo-learn
npm install
```

### Запуск

```bash
# десктоп, для быстрой отладки интерфейса
npm run tauri dev

# Android (эмулятор или устройство)
npm run tauri android dev

# iOS (симулятор или устройство)
npm run tauri ios dev
```

### Сборка

```bash
npm run tauri android build
npm run tauri ios build
```

## Темы и цвета

Тема (светлая или тёмная) и акцентный цвет задаются через CSS-переменные в `styles.css`. Переключатель темы меняет атрибут на корневом элементе, а акцентный цвет пересчитывает остальные токены палитры.
