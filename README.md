# NeoLearn
Neo Learn — тренажёр программирования для iOS и Android. Учите Rust, C++ и JavaScript короткими уроками и практикой: без лишней истории и теории, которая не нужна при работе с языком. Несколько уровней сложности, поиск по урокам, PDF-конспекты, светлая и тёмная темы. Мягкий интерфейс в стиле неоморфизма и Material Design 3.
